# Routes

- `/` — public confectionery landing page and order form.
- `/crm` — new hidden service page for locally stored orders.
- `/api/orders` — validates, persists and then notifies Telegram.
- `/api/crm/orders` — new internal JSON endpoint for listing and changing statuses.
- `/api/consultant` — Gemini sales consultant.
- `/api/telegram/webhook` — Telegram assistant webhook.
